# 咖啡馆：Yarn、咖啡 QTE 与手机干扰

在 feat/Cafe 上新增 CafeGameplay 场景，保留 CafeDraft 视觉稿。

流程：客人入场 → Yarn 讲述 → 三步咖啡操作 → 结果返回 Yarn → 完美结果解锁更深对话，普通结果可重试或继续 → 剧情开启手机通知 → 点击桌面手机、画面向下移动 → 滑动消息/广告卡片，查看新内容增加全局 Meter → 收起手机回到客人。

可复用部分：CoffeeQTE.prefab、CafePhone.prefab。配置资产分别保存配方步骤、判定范围、计时与手机消息内容。Yarn 命令只负责启动交互和读取结果，不把台词写入交互代码。

通知默认关闭；开启后定时产生提示，声音可关闭。自动打开默认关闭，开启时也不会打断 QTE、菜单或剧情选项。到达通知上限停止排队，不无限堆积。看过的同一内容不重复加分。通知开关不由 Meter 自动决定，剧情可以精确控制。

测试重点：各 QTE 判定边界、超时、暂停冻结、重复输入、取消清理；手机开关、通知上限、QTE 阻止打开、同一内容去重；完整真实 Yarn 流程及截图。场景内状态不接入存档，本轮不增加重生点。
